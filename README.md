# Hội Quán Web

Website dịch vụ thiết kế website — SEO-first, responsive, customer-focused.

## Preview

The project is configured for GitHub Pages deployment. After the first deployment, open **Settings → Pages** to find the published URL. Each push to `main` triggers a fresh deployment.

## Local development

This initial version is a static HTML/CSS/JavaScript website and can be previewed by opening `index.html` or using any static server.

## Roadmap

- Phase 1: Brand website, service pages, portfolio, SEO foundations, responsive design.
- Phase 2: Project brief, quote estimator, consultation booking and lead capture.
- Phase 3: Customer portal, project milestones, design feedback and approvals (requires backend/auth).
- Phase 4: CMS/CRM integrations, analytics, support and operational automation.

Features that require persistent data, authentication, payments or external integrations must be connected to real services before production use.
